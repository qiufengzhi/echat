## 目录结构约定

每个案例目录包含两个文件：

```
案例名（kebab-case）/
├── case-study.md          # 复盘案例文档：问题→背景→排查时间线→根因分析→方案→教训
└── investigation-log.md   # 原始排查日志：按时间顺序的每一次尝试记录
```

- **case-study.md**：给人读的，结构化的完整复盘。新成员或未来自己回顾时，先读这个
- **investigation-log.md**：给 AI 接手的，包含每次假设、改动、验证结果。排查同类问题时，AI 应先读这个了解来龙去脉，避免重复尝试

## 如何新增案例

1. 在 `docs/deep-dives/` 下创建以问题命名的 kebab-case 子目录
2. 将排查过程中的原始日志整理为 `investigation-log.md`
3. 写一份 `case-study.md`，包含问题概述、系统背景、排查时间线、根因分析、解决方案、经验教训
4. 在本文件的案例列表中追加一条记录
